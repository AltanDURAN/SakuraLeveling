# Emblèmes de rang (fiche joueur admin)

Dépose ici une image PNG (fond transparent recommandé) par tier, nommée
exactement comme le tier. Elle s'affiche comme BASE sous la fleur de sakura +
la lettre de rang sur la fiche joueur.

Fichiers attendus (l'un des noms ci-dessous par rang) :
  iron.png        (rang F)
  bronze.png      (rang E)
  silver.png      (rang D)
  gold.png        (rang C)
  platinum.png    (rang B)
  emerald.png     (rang A)
  diamond.png     (rang S)
  master.png      (rang SS)
  grandmaster.png (rang SSS)
  challenger.png  (rang SSS+)

Taille conseillée : ~150 px de large, ratio proche des emblèmes (un peu plus
large que haut). L'affichage est capé à 78×52 px.

Si un fichier manque, la fiche affiche un repli : la fleur de sakura teintée
selon la couleur du tier (aucune image requise pour que ça marche).

NB : ces emblèmes (ex. ceux de League of Legends) sont la propriété de leurs
ayants droit. Usage sur un outil admin PRIVÉ uniquement — ne pas redistribuer.
