# Prompts des images d'objets — 2e lot

Les 40 objets dont l'image datait d'avant le 1er lot, pour que tout le jeu ait le même style. Chaque bloc
est **complet** : copie-le tel quel, une image par message, dans ChatGPT ou Gemini.

**Pour garder le style du 1er lot** : joins à ton premier message 2 ou 3 images du 1er lot (par exemple
`assets/items/rapiere_ecarlate.png`, `assets/items/sceau_souffle_b.png`, `assets/items/potion_soin_totale.png`)
et ajoute « dans le même style que les images jointes ». Les anciennes images de ce lot ne servent plus de
référence : elles vont être remplacées.

**Gemini** peut ajouter son petit logo ✦ dans un coin : vérifie avant d'importer.

**Importer** : site admin › Objets › ouvrir l'objet › champ image › Enregistrer (la nouvelle image remplace
l'ancienne). Le formulaire garde désormais les stats en % des pièces (corrigé le 03/11/2026).
