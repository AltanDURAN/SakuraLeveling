# Prompts des images d'objets

Un prompt par objet qui n'a pas encore d'image (65 objets). Chaque bloc est **complet** : copie-le tel quel,
une image par message, dans ChatGPT ou Gemini.

**Pour que tout reste dans le même style** : joins à ton premier message 2 ou 3 images existantes
(`assets/items/couronne_de_la_liche.png`, `assets/items/egide_du_damne.png`, `assets/items/potion_soin.png`)
et ajoute « dans le même style que les images jointes ». Le fond blanc est voulu : toutes les images du jeu sont
sur fond blanc (pas besoin de transparence).

**Gemini** peut ajouter son petit logo ✦ dans un coin : vérifie avant d'importer (à rogner sinon).

**Importer** : site admin › Objets › ouvrir l'objet › champ image › Enregistrer (converti en PNG, rangé sous
`assets/items/<code>.png` et poussé sur git). Ou dépose les fichiers nommés `<code>.png` dans `assets/items/`.
